# Web client guide (`web/`)

Read this before changing the client. React + TypeScript + Vite + Tailwind CSS v4, pnpm.

## Layout

- Feature folders under `src/features`: `player`, `actions`, `trades`, `stores`, `account`.
- Typed API client in `src/api` (`openapi-fetch`); `schema.d.ts` is generated by `pnpm gen:api` from a running API, never hand-edited.
- `src/content/labels.ts`: paints, icons and sprites only. `src/content/text.ts` resolves content names.
- Design tokens in the `@theme` block of `src/index.css`. Visual direction in `PRODUCT.md` and `DESIGN.md` at the root ("Guild Signboards": each trade hangs a painted sign; limestone ground, oxblood band, one paint per trade, ochre only for what is working; Grenze Gotisch for the wordmark and trade names only, Alegreya Sans for everything else). Pixel art rules in `docs/art-direction.md`.

## Rules

- The client never computes rewards, XP or levels. It animates the working bar locally and refetches when a cycle ends; numbers on screen come from the server.
- Server state goes through TanStack Query.
- **i18n**: English and Brazilian Portuguese with react-i18next. All UI copy and content names (with plural forms) live in `src/i18n/locales/en.ts` and `pt-BR.ts`; `pt-BR` is typed against `en`, so a missing key fails the build. Never hard-code UI text. In `<Trans>`, never name a tag after an HTML void element (`<link>`, `<input>`...): use names like `<action>`.
- `localStorage` only through `src/lib/storage.ts` (it can throw).
- `erasableSyntaxOnly` is on: no TypeScript parameter properties or enums.
- A component file exports only components (oxlint `only-export-components`); helpers go in a sibling `.ts` file.

## Accounts in the client

`features/account` holds the `/account/*` queries, the sign-up/sign-in dialog (native `<dialog>`), the header menu, the save nudge (shown to a guest once a trade passes level 1, dismissal kept in localStorage) and the signed-out screen.

The player query is keyed by mode (`['player', 'guest' | 'account']`): guests use `/players/{id}`, signed-in players `/me/player`. A 403 (`HoldOwnedError`) or 401 (`SessionEndedError`) stops retries and polling. After signing out the browser keeps the hold's id, so the guest view gets 403 and asks to sign in.

## Tests

Vitest + Testing Library. Copy the style of `src/features/account/AccountForm.test.tsx`: queries by role and accessible name, one short sentence per test name. The setup file switches i18n to English.

## Commands (from `web/`)

- `pnpm dev` (http://localhost:5173, proxies `/api` to the API on :5085).
- `pnpm test`, `pnpm typecheck`, `pnpm lint`, `pnpm build`.
- `pnpm gen:api` with the API running.
