# Working with the project owner (Claude)

- Talk to the project owner in **Portuguese**. Everything inside the repository stays in English.
- **Explain** what is being done and why. Before adopting a technology or pattern, present the trade-offs; the project owner decides.
- Visible engineering quality: clear architecture, tests, a good README, a clean commit history.
- Before working in `src/`, `tests/` or `web/`, their own guide loads with the files (`src/AGENTS.md`, `web/AGENTS.md`). For anything else, follow the table in `AGENTS.md` and read only what the task needs.
- Record every technical decision in `docs/decisions.md`, not here: this file and `AGENTS.md` load in every session, so they stay short.
